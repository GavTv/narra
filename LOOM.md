# Loom-питч Narra (3–5 мин)

Записывай на live URL или localhost. Говори спокойно, показывай экран.

## 0:00–0:30 — Хук
«Устали от сырых CSV и Excel. Narra за минуту превращает отчёт в историю, графики и чат по данным — без регистрации.»

Покажи лендинг.

## 0:30–2:00 — Демо продукта
1. Загрузи CSV или Excel (или «Демо-отчёт»).
2. Покажи loading → narrative hero.
3. Пройдись по 2–3 графикам (тип выбрал AI).
4. В чате спроси:
   - точный вопрос по цифре («сколько всего…»);
   - вопрос вне данных («какой курс доллара?») → честный отказ.
5. Покажи citations / grounded ответ.

## 2:00–3:30 — Как оркестрировал AI (главное для оценки)
Скажи прямо:
- Cursor = команда разработки: декомпозиция MVP, UI, Zod-схемы, RAG.
- Я = PM + art director: скоуп, вайб, где резать сложность.

Промпты (озвучь 2–3):
1. «Собери Next.js MVP без auth: upload → narrative → charts → grounded chat».
2. «Строгий JSON дашборда; числа только из отчёта».
3. «Не усложняй RAG: lexical retrieve + deterministic calc + LLM».

Где AI ошибся и как правил:
- пакет `xlsx` уязвимый → заменил на `read-excel-file`;
- chat «что продалось меньше» сыпал «данных нет» → поправил sales Q&A + citation validation;
- pie-инсайт иногда врал про максимум → поправил локальный fallback.

Архитектура в одном предложении:
«Тонкий API → толстый server use-case → чистый domain; клиент только UI и fetch.»

## 3:30–4:30 — Trade-offs
- Без auth / без БД — по anti-scope.
- Не векторная БД: для ≤500 строк BM25-like достаточен и контролируемее.
- Fallback без ключа — демо всегда живо.
